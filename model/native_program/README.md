# Typed native programs and complete service accounting

This package admits finite literal programs built from the existing native
C/E repair instruments. It executes an actual continuing one-cell observer,
preserves the existing global binary federation grammar, and checks membership
of the retained record-derived clock observer. It supplies evidence for a
reviewed source-class and observer boundary. It does not select a physical
field action, particle spectrum or calibrated clock.

```sh
python -m pytest -q -W error model/native_program
python -m model.native_program.receipt --check model/native_program/results.json
```

`interpreter.admit` fixes the carrier, state algebra, local weight family,
literal record-only selector, complete law tags, finite repeats and FIFO policy
before a source state is passed to `execute`. The state may be entangled with
an arbitrary untouched reference. Exact rational sparse operators cover the
real and imaginary parts of every matrix unit. Each raw branch is a weighted
partial injection; its effect is a domain projection and the complete effects
sum to the identity. The independent certificate checks every source column
on H78 and H66, both laws and all thirty seams. Positivity and preparation of
the input state are declared preparation obligations.

The admitted carriers are H78/H66, finite independent tensor products of those
carriers, and the full global fixed-number binary sector of the existing
`port_pair` geodesic federation. A product action identifies its factor with a
literal cell address. A federation action can cross actual joining seams and
transfer occupation between cells. It does not impose total-two occupation on
each cell. Products and federation growth are distinct constructions.

Native commands are repair or hold. Repair selectors are fixed seams, the
weighted full seam menu, last-current feedback, or the original mixture of
exploration and last-current feedback. The law can be C, E, a tagged rational
mixture, or the fixed alternating training schedule. No callback, hidden source
state selector, arbitrary operator or target Hamiltonian is accepted. Raw C/E
register padding and zero law weights remain explicit output blocks. FIFO
overflow exports the oldest record or emits a timeout that preserves source
and memory. The entire history is the exported archive plus current FIFO and
terminal status, not a postselected successful trajectory.

Admission allows at most4096 command nodes, each repeated at most2^32 times,
with at most2^32 total native attempts and2^40 retained record bits. Coherent

Resource declarations must equal independently recomputed counts. Source
preparation, blank FIFO slots, draws, controller reads, record writes, archive
storage, source pulses, proper-code load/export and supplied initialization
are included. These are semantic service counts, not claimed physical energy
or duration costs. The resource ceilings do not certify that a given run is
feasible on available hardware.

The local evaluator supports federation levels0–2, at most64 independent
factors,64 attempted steps and65536 expanded history blocks. Larger admitted

returns its supplied operator without asserting that its state domain has

`source_word` and `execute_word` use the existing six-level compiler kinds
X/Y/Z/I/H/J. An angle is a canonical rational string representing exactly a
finite binary64 value, bounded in magnitude by2^20. Every pulse performs the
existing supplied proper-code load, actual six-level response, and complete

with work spectators and the quantum reference. Success is never normalized
or corrected to a nearby unitary. Generic words act on a declared coherent
work register; a native-carrier embedding must be supplied and bound separately.
Malformed words produce a retained rejection before any pulse. Evaluator limits
are6 work qubits and256 pulses; larger words are counted and resource-stopped.
