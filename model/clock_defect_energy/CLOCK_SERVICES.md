# Clock services for every transported two-port core

The [successor contract](joins_campaign.json) extends the clock-service menu
from four to all 66 transported reference cores at modular parameter `s=4`.
Each word is generated by the existing source compiler, executed on every
one of its 512 input addresses, and checked against rational phase
enclosures. This adds 62 compiled services. It changes neither the C/E repair
law nor the earlier [unavailable-service result](CONTINUATION.md), which
describes the original four-word menu.

The extension uses the existing supplied complex controls and coherent
proper-code load/export services. It closes a finite compiler-coverage gap;
it does not derive that apparatus from passive repair or identify a physical
clock. Other modular parameters require fresh compilation and certification.

```text

(a[0],a[1],a[2]) = (2/225, 1/36, 2/45).
```

The target state action is `sigma_A^(-is)`, up to the same native scalar
phase in every core. On the 66 encoded native addresses the compiler uses
ratios `60 sigma_A(x)`; on all other 446 addresses its target is identity.
No reference state or modular logarithm on that padding is inferred.
The full reference remains an extension, not a normalized posterior corner
or the stationary source/FIFO reference.

The existing closed Gray-Walsh construction expands the address phases and
executes them using `I`, `Z`, `H` and `J` source requests. Its schedule has
512 phase requests and 510 three-pulse controlled-NOT words: **2042 native
pulses per request**, including zero angles. No target unitary is substituted
for the source execution, and no polar correction or normalization is made.

## Execution, errors and complete failures

`clock_services.py` freshly executes and certifies all 66 full source arrays.
For each original array `A` and its target `U`, the existing rational checker
bounds the Frobenius error, hence the operator error, by the fixed gate
`epsilon=10^-9`. Every diagonal, off-diagonal and padding entry is included.
The recorded gate is a conservative certified bound, not the floating
residual of one selected input.

For arbitrary reference extensions, the corresponding half-diamond error
is at most

```text
delta = epsilon(2+epsilon)/2,
channel norm <= g = (1+epsilon)^2.
```

The classical core selector takes the maximum word error; it does not sum
errors over the 66 menu entries or over histories. Interleaving `n` requested
words with the exact complete native instruments gives the conservative
bound `(g^n-1)/2`. For 24 requests this is less than `25*10^-9`. This bound
compares the executed clock arrays to the ideal clocked native process.
Physical service errors, hardware workspace and additional native numerical
errors are not silently included.

Every request exports a `success` block on `H66 tensor R` and an
`export_abort` block on `R`. The latter traces out the escaped padding
address while retaining its reference state. Neither block is normalized.
For native input, the ideal target has zero terminal abort, while the
executed-array certificate bounds its abort probability by `epsilon^2`.
Per-pulse proper-code complement outcomes also remain in the inherited
service contract; their ideal probability vanishes by exact invariant-code
identities, rather than by a postselection assumption.

The conditional preparation join accepts all four original terminal flags.
It applies the clock only to `success` and copies herald failure, warmup
timeout and completion timeout unchanged. The inherited finite-preparation
sandwich theorem remains applicable to actual history corners; this packet
does not re-prepare the reference after a repair or hide an unsuccessful
preparation. The preparation's full attempt/error budget is retained in the
receipt, separately from the word error.

An independent failure control injects a unitary rotation from a native
address into padding. It produces a nonzero abort carrying the corresponding
reference component, with total probability preserved. Wrong-core words and
an altered source phase fail the rational target certificate. These controls
test the actual export/certificate paths rather than replacing failure with
a status label.

## Complete continuation checks and resources

The clock-before/clock-after experiment retains all 497 semantic native slots
for each of C and E, including zeros. It uses an entangled source/reference
probe and the newly compiled source words, retaining input-clock and every
output-clock abort separately. Exact covariance and the word bound give the
arbitrary-input certificate. Floating complete-output, mass and reference
residuals are checked under a separate diagnostic ceiling; they are not
presented as the proof of that error bound.

A second execution follows four native exploration attempts along seams
`(0,7)`, `(6,7)`, `(2,6)` and `(2,3)`. The decoded currents transport the core
from `{0,1}` to `{1,3}`, outside the old menu. Three records have already
exported; one remains in the FIFO. The surviving history corner has more than
one coordinate, so its clock comparison still tests coherence. Both C and E
retain the unnormalized branch weight and execute the new endpoint word.
