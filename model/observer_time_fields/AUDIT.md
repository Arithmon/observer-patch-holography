## Contract and independent checks

The source is the retained fair native endpoint rule, uniformly scheduled
over all source seams. The elementary instance uses 66 configurations; the
federation uses all 28,680 fixed-two configurations on its actual 240 ports.
Both disclose only the two initial read-port occupations. Four alternating
reads and optional first-bit-controlled internal repair are fixed before
computing their complete laws. Source instances and their different clock
regions are not identified with each other.

The exact elementary certificate checks the resolvent order `K(I-A)=B`,
the triangle polynomial, all local dictionary commutators and complete
probability mass. An independent symmetric-transfer calculation reproduces
every one of the 64 field words for both feedback choices. Its transformed
hidden terminal distribution is deliberately tested to differ from the
native distribution: equivalence is of the declared record law, not every
unobserved state coordinate.

For the federation, independent calls to the original endpoint function
reconstruct remote, incident and feedback operator columns. A direct rational
native-coin oracle evaluates every terminal population of a nonstationary
two-tick experiment, with and without feedback. It checks each stored integer
population as a lower bound, as well as the total missing mass and exact
timeout probability. A separate Python-integer oracle checks multiplication
and division near the production `2^51` scale. Tests compare coarse and fine
integer grids and retain both successful and timed-out branches.

The full production protocol retains 124 outcomes. Its eventual fourth
cumulant uses exact interval arithmetic over all 15 partitions, including
missing arithmetic mass and timeout mass. The feedback witness compares
intervals on the continuing second field. No floating eigensolve, fitted
normalization or success conditioning supplies these certificates.

## Findings fixed before publication

- A frozen dataclass still has a mutable envelope. The elementary cached
  structures now use immutable named tuples; federation public arrays and
  envelopes are detached from caches. Tests mutate shape metadata and caller
  envelopes without changing subsequent executions.
- A matching self-supplied hash authenticates no source calculation. Public
  federation budget/statistics/resource readers now compare against the
  actual source producer for validated parameters, recomputing on a cold
  cache. Resealed wrong outputs and resealed feedback policies are rejected.
- Caller-owned writable arrays are copied before value/hash validation.
  A deterministic mutation at the former hash/copy boundary is rejected;
  the checked snapshot is exactly the returned snapshot.
- Initial field disclosure must include both subsequently read ports. All
  four initial labels, including zero-probability continuations, remain in
  the output. Signed-current readback is checked against source transitions.
- The feedback repair is an additional incident tick. Its clock coordinate
  and native operation cost are charged explicitly; it is not silently
  counted as an uncontrolled effective-transfer step.
- The finite cutoff counts global scheduler attempts, including remote
  attempts. Its supplied counter/timeout service is distinct from the
  incident clock and unnecessary for the completed law. The reported
  fourth-cumulant interval is explicitly labelled as the baseline result.
- Tests cover malformed inputs before cache lookup, ndarray subclasses,
  missing outcomes and modified exact receipt values. The CLI writes a real
  producer receipt, reads it back through strict JSON, and rejects a changed
  certificate. Source-binding paths use repository-relative `/` names.

The movement-only clock retains its exact negative mode; an external field
fails the required dictionary commutator; replacing remote motion by scalar
holding changes the continuing law. These are retained boundary controls,
not inconvenient cases removed from the claimed domain.

Isolated-process mutations were also run against the actual scientific
assertions. Reversing the elementary resolvent and replacing its remote map
by scalar holding each failed `K(I-A)=B`; disabling its feedback failed the
complete-law contrast. On the federation, upward rounding failed the
independent Python-integer oracle. Scalar remote holding and identity in
place of feedback both preserved subchannel mass, but failed the independent
source-column comparison and full terminal-population oracle. All six
mutations were caught; this is a targeted check, not mutation completeness.
