# Execute the native C/E discrimination experiment from source controls

The existing [prediction package](../../predictions/README.md) specifies two
quantum repair instruments with identical classical load transitions. This
package implements **both complete instruments**, their coherent preparations
and their binary readout through emitted twelve-port control words. It reuses
the [six-level source compiler](../source_scalar/compiler.py) and leaves the
registered prediction protocol unchanged.

The result is an encoded construction on all 78 native configurations.
The [derivation](DERIVATION.md) proves equality of the recorded channels on
all 6,084 matrix units, hence also with an arbitrary reference system.
Numerical execution then compares every unnormalized terminal density block
with the independent exact prediction, including the conditional blocks of
both retained preparation-randomizer outcomes. The verifier requires the full
unique record grid, correct raw-to-public labels and finite unmasked vectors.
Coin, current/contrast, preparation
randomizer and readout records remain present; no successful subset is selected.

## Reproduce

Install the repository's `model/requirements.txt`, then run:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -m model.observer.source_discrimination --check model/observer/source_discrimination/results.json
python3 -m pytest -q -W error model/observer/source_discrimination
```

`--write PATH` creates a new receipt and refuses to overwrite an existing
file. `--seed INTEGER` changes only the synthetic count draws. The replay
requires exact structure, counts, rational certificates, source hashes and
scientific-status fields; only floating diagnostics use absolute tolerance
`2e-10`. Duplicate JSON keys and nonfinite diagnostic values are rejected.
`model.verify` binds every package artifact and reproduces the receipt.

## Construction and result

`circuit.py` embeds the endpoint occupation in three bits and spectators
in six. A local permutation with blank record bits realizes each repair;
its phase-exact transpositions are expanded into source Pauli words.
The fair placement coin itself is prepared by a source pulse and recorded.
The preparation starts from a blank register and executes its Y, identity
and Z phases, including zero-angle requests. The diagonal control is a
recorded mixture of the phase-zero and phase-pi preparations generated by
an additional source coin.

The readout couples the rank-one plus projector to a blank pointer. Only
the pointer is measured. This preserves the entire rank-77 native minus
subspace, including its coherence; reading the full computational basis
would implement a different instrument even if its plus frequency agreed.

| Preparation | C plus probability | E plus probability |
| --- | --- | --- |
| Phase zero | 5/8 | 3/8 |
| Phase pi | 1/8 | 3/8 |
| Phase pi/2 | 3/8 | 3/8 |
| Diagonal control | 3/8 | 3/8 |

Actual source execution recovers these probabilities and the full output
densities. The receipt samples 8,192 attempted trials per setting directly
from executed branch norms. For each dataset, the fixed evaluator does not
reject its generating candidate and rejects the alternative under the
comparison contract. These are synthetic controls,
not independent observations. The sampler's floating mass correction is
reported separately; quantum amplitudes are never renormalized. Every reserved
record code is kept as an abort outcome, including zero-probability outcomes.
The synthetic sampler uses one Python uniform draw per attempted trial and
cumulative executed branch norms. This avoids a binomial algorithm changing
its random-number consumption when execution roundoff crosses probability
one half. The receipt declares that sampling algorithm; no target probabilities
are substituted and no scientific tolerance is relaxed.

## Complete attempted-trial costs

| Resource | C pure | C diagonal | E pure | E diagonal |
| --- | --- | --- | --- | --- |
| Native pulse requests | 32,006 | 32,007 | 32,009 | 32,010 |
| Proper-code loads | 32,006 | 32,007 | 32,009 | 32,010 |
| Proper-code exports | 32,006 | 32,007 | 32,009 | 32,010 |
| Peak live code qubits | 11 | 11 | 12 | 12 |
| Retained classical bits | 4 | 5 | 5 | 6 |
| Blank-register initializations | 4 | 5 | 4 | 5 |
| Classical readout channels | 3 | 4 | 3 | 4 |

Blank initializations are the nine-bit source, fair coin, repair-record
register and pointer, plus the optional independent randomizer. Repair
registers can be released after their records are committed; the pointer
can then reuse their quantum storage. The six-level processor is additional
to the listed code storage. Classical readouts commit the coin, repair
record and pointer, plus the optional randomizer. This counts registers,
not individual bit resets or bit readouts.

Both repair coin branches have equal resource costs. For the diagonal
setting, norm costs use the phase-pi branch, which is the larger one;
`zero_angle_requests` describes that declared branch. The pure phase-zero
branch has two additional zero requests but the same pulse/service counts.
Each readout costs 26,632 pulses; local C/E repair costs 5,370/5,373.
The construction establishes realizability, not optimal compilation cost.
Large flat pulse tapes are regenerated by `circuit` functions rather than
committed as redundant artifacts.

## What this closes, and what it does not

The native repairs and their fixed interference test have a common
source-control realization. They no longer require inserting an arbitrary
Kraus map, coherent input density or final source projector into the executor.
`certificate.py` and the full-vector tests check this connection separately
from the exact prediction package. Wrong relative phase, erased contrast
records and an overmeasured minus space are detectable even where a scalar
probability or classical transition check would pass.

There is also a concrete selection result: the same source alphabet and
classical endpoint transitions admit both constructed quantum instruments,
whose common observable differs by 1/4. Thus those ingredients alone cannot
select the quantum record law. The additional selection must constrain
which information is recorded, and the fixed experiment makes that choice
observable. This bounded counterexample does not assert that both candidates
satisfy every OPH axiom.

More precisely, E is C followed by recording one bit: seam-total parity
`p=(a+b) mod 2`. The original contrast is recovered as
`d=2*j+(2*c-1)*p`. Given coin and current, two parity outcomes are necessary
and sufficient to distinguish E's additional record values; this is a
minimal classical refinement, not a hardware lower bound. The source word
copies that bit with one three-pulse CNOT after the shared C repair.
Forgetting the parity label afterwards leaves the source dephased and does
not recover C's interference. The two laws thus share the entire repair
circuit and differ only by this explicit recording operation.

The encoding is a mathematical isometry. A physical interface taking
occupation states to that code has not been established. Proper-code
load/export, blank initialization, record acquisition, storage, classical
control and computational pointer readout remain supplied services. The
source executor retains their declared complete complement/failure contract;
this package does not simulate arbitrary faulty hardware.

The derivation gives a compositional, reference-uniform error bound for the
complete attempted trial. Its sufficient condition is
`N_p*u + N_l*l + N_e*e + p+z+c+a+r+s+m+g+n <= 1/64`, with every term defined
and required explicitly. An equal illustrative allocation at the largest
schedule is `1/6146496` per pulse/load/export bound and per remaining
aggregate term. This is a required precision target, not an achieved
calibration. Floating residuals do not certify physical error or roundoff.
Trial independence and apparatus identification remain the prospective
protocol's premises. Neither candidate is selected as the physical law,
and neither a complete OPH model nor the separate eight-mode scalar
benchmark is claimed.
