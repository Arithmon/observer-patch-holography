# P-dependent electromagnetic observation and native feedback

Conditional hardware design and executable finite protocol.

**This implements the connection: closure pixel P → electromagnetic
charge → a recorded binary observation → the next native repair.** P changes
the detector's actual probabilities and the subsequent native current. The
controller receives only the new detector bit.

The construction takes P and N as closure-derived inputs. The apparatus,
charge assignment, protocol and controls are explicit design choices.
The software implements a conditional finite observer; its validity does
not depend on a uniqueness claim for the microscopic law.

Run from the repository root with Python 3.10 or newer; this module uses only
the standard library:

```sh
python3 -m model.observer.p_response --check model/observer/p_response/results.json
python3 -m unittest model.observer.p_response.test_experiment -v
```

The first command evaluates the coupling, enumerates every history, executes
200,000 seeded trials and compares the complete receipt byte for byte.
Use `--write /path/to/new-results.json` to save a fresh receipt instead.

## The implemented map

The program imports the pinned forward-closure P interval and **executes**
the existing `PaperMathContext.build_d10_from_p(P)` and
`alpha_external_from_d10(..., 'thomson_structured_running')` functions.
It uses their declared low-energy branch, without substituting a measured
alpha or confusing it with the electroweak anchor:

```
P                 = 1.63097209585889737696451...
alpha^-1(P)       = 136.994835177412937...
g(P)=sqrt(4π α(P)) = 0.302867613116883569191349...
```

This is the existing source-only structured-running convention, including
its modeled hadronic transport. Its physical endpoint status is unchanged;
the closure premise makes it an input to this conditional design. The program
compares its evaluation with the pinned certificate's midpoint within `1e-13`
and recovers the outer closure numerically. Its point
error is about `3e-19` in alpha, larger than that narrow certificate's
interval width; the printed digits are numerical output, not 24 certified
digits. It does not rerun or alter that certificate.

Use Heaviside–Lorentz natural units with `ħ=c=1`. We **choose** the charged
realization `Q_v=g(P) N_v`. A native current record j then means exactly
`ΔQ_a=-g(P)j`, `ΔQ_b=+g(P)j`; total charge is conserved. This identifies a
physical response channel for the native load, without asserting that all
Standard Model matter has been derived from that assignment.

The detector is a unit-charge path qubit prepared in `+X`. The earlier native
record routes it around a prescribed electromagnetic loop with orientation
j, taking zero effective loop when j=0. The closed-loop exposure is
`χ=∮A·dx`, so the relative phase is `φ=g(P)jχ`. This is the ordinary
[Aharonov–Bohm phase principle](https://journals.aps.org/pr/abstract/10.1103/PhysRev.115.485),
used as an apparatus design. Here χ is a prepared, calibrated external flux;
it is not claimed to be a field spontaneously generated by the native charge.

A Y read of the probe produces the **single stable detector bit** `y=±1`:

```
Pr(y | j,P,χ) = [1 + y sin(g(P)jχ)]/2.
```

The main design fixes `χ=1` independently of P. The two outcomes are both
retained. At j=+1 the plus-bit probability is **0.649129261647**; at j=-1
it is **0.350870738353**; at j=0 it is exactly 1/2. Zero coupling or exposure
gives a fair uninformative bit. Reversing j reverses the bias. The actual
binary detector need not perfectly distinguish the richer native state.

The geometric aperture is separately tied to P:
`A_loop=K_loop P ell_star²`. At fixed χ its uniform normalized flux density
is `B ell_star²=χ/(K_loop P)`. The displayed `K_loop=1` is an area
normalization, not a claim that the whole apparatus fits in one pixel.
Any feasible larger aperture can keep the same χ by changing the field.
Alternatively, holding `B ell_star²=β` fixed gives
`χ=K_loop P β`, adding explicit geometric P dependence. The primary
comparison holds χ fixed to isolate coupling dependence.

## End-to-end continuation

Start with the uniform 66-state binary total-two native source:

1. Native C repairs `e=(0,1)` and supplies its current record `(c1,j1)`.
2. The designed probe uses j1 to set its loop orientation, measures Y and
   commits its result y. This is electromagnetic transcription of an existing
   record, not newly learned information about that record.
3. The actuator receives **only y**. It chooses `f=(0,5)` for y=+1 and e
   for y=-1, applies the fair native repair, and retains y unchanged.
4. The two-event protocol halts. The second native current j2 is readable
   from its ordinary event record.

Every one of the **528** state/coin/detector/coin histories has positive
probability at the main setting and is retained in [results.json](results.json).
No trial or outcome is filtered. The exact symbolic result is

```
E[y]  = 0
E[y j1] = (5/33) sin(g(P)χ)
E[j2] = (5/264) sin(g(P)χ)
E[g(P)j2] = (5g(P)/264) sin(g(P)χ).
```

At the computed P and χ=1, the mean second current is
**0.00564883566843**, and its mean transported charge is
**0.00171084937579** in these natural units. Disconnecting the probe or
independently shuffling its bit gives mean current zero while preserving
the same half/half detector and seam frequencies. This effect is observable
on the native record tape; it requires no extra occupation meter.

For weak exposure the physical response is

```
E[g j2] = (5π/66) α(P) χ + O(χ³).
```

Thus alpha controls the response magnitude in the implemented loop, rather
than appearing only as a unit label. The equivalent full-source audit gives
final port-0 occupation `0.161017830998235`, versus `1/6` for disconnected
or shuffled control. Off-closure controls at `0.999P` and `1.001P` recompute
the same source map and change the detector and feedback probabilities at
fixed χ. They are parameter checks, not additional closure solutions.

The action controller exposes one stable bit and a protocol phase. Its bit
algebra has two readable alternatives. The richer retained scientific audit
also keeps r1 and r2: it has **24 terminal words**, **37 reachable prefixes**,
and a six-bit classical prefix encoding. These counts are not the capacity

[DERIVATION.md](DERIVATION.md) gives the quantum instrument, all-input CPTP
argument, classical-record preservation, charge-transfer covariance and exact
feedback calculation. Classical durability is preserved; unknown quantum
record coherences need not be. [The validation](VALIDATION.md)
checks these claims and the charge/coupling conventions.

Validation covers **15 calculation checks and six independent tests**, all
528 weighted histories, zero/reversed/weak/perfect-exposure controls,
source-map agreement, bit-only actuator access, and arbitrary coherent
record inputs to the detector. A separate fixed-seed sequential run executes
**200,000 trials**, retaining counts and the sample current's standard error;
the analytic complete-history expectation remains the reference result.
The observed mean second current is **0.006390**, with standard error
**0.00085715**, consistent with the analytic **0.00564884**.

The only observation-time parameter here is the finite protocol order and
the prescribed integrated exposure. No physical clock duration or universal
tick is inferred. P and N constrain an eventual physical realization; N
does not determine a local exposure or require the whole available capacity
to be allocated to this observer. This construction supplies a usable
finite interface under the accepted premises, without extending the claim
to a complete cosmological implementation.
