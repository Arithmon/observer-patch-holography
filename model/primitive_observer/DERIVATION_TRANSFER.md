# A finite Hamiltonian reconstructed from the native history

The uniform native binary process determines a positive transfer matrix and
therefore a unique self-adjoint generator `H = -log K`. Its transfer
correlations reproduce an actual observer readout: whether each of two
native events carried nonzero current. This is a finite Euclidean-history
reconstruction. It supplies no physical clock, spatial continuum or
identification of its unitary analytic continuation with native repair.

The inputs are the existing twelve-port icosahedral carrier, the binary
total-two sector, uniform independent selection of its thirty seams and
the fair native placement coin. Neither an oscillator Hamiltonian nor its
coefficients enters the construction. The production observer's adaptive
two-seam policy is a different schedule.

## Kernel and exact positivity

Let `X` be the 66 binary configurations. Enumerating the sixty seam/coin
choices from each configuration gives integer counts `N_xy` and
`K_xy = N_xy/60`. Rows and columns sum to one, and `N_xy = N_yx`.
The uniform law `pi_x = 1/66` is stationary.

An event across unequal endpoints either waits or exchanges the occupied
endpoint. Each possible exchange has probability `1/60`. The configuration
graph is consequently the two-token graph of the source icosahedron:

```
K = I - L_token/60.
```

The degree of a configuration is eight if its occupied ports are adjacent
and ten otherwise. The exact census is thirty degree-eight and thirty-six
degree-ten configurations. The minimum diagonal entry of `K` is `5/6`.
The implementation checks these counts and a 65-edge spanning tree.

For any complex vector `v`, the graph identity and
`|v_x-v_y|^2 <= 2|v_x|^2+2|v_y|^2` give

```
0 <= v* L_token v = sum_edges |v_x-v_y|^2 <= 20 ||v||^2,
(2/3) I <= K <= I.
```

This exact bound proves positivity independently of floating eigenvalues.
Connectedness makes the zero direction of `L_token`, and thus the
eigenvalue-one direction of `K`, precisely the constant vectors. Positivity
and the spectral theorem give a unique self-adjoint logarithm, with
`H=-log K >= 0`, a unique ground direction, and a positive finite gap.
The reported gap is a numerical diagnostic in inverse Euclidean attempt
units. It is not an experimentally identified mass.

## Reflection positivity for the full finite history

Consider the stationary two-sided Markov history generated by `(pi,K)`.
Reflect about the bond between configuration times zero and one:
`theta(X)_n = X_(1-n)`. Let `F` be any complex cylinder function depending
on a finite portion of the future starting at time one, and define
`f(x) = E[F | X_1=x]`.

Reversibility identifies the conditional distribution of the reflected
past with the corresponding future distribution. Given `X_0=x` and
`X_1=y`, the remaining past and future are conditionally independent.
Therefore

```
E[conj(F(theta X)) F(X)]
    = sum_xy pi_x K_xy conj(f(x)) f(y)
    = (1/66) f* K f
    >= (2/198) ||f||^2 >= 0.
```

This proves bond reflection positivity for every cylinder function, not
only for configuration two-point functions or a Gaussian approximation.
Complex-valued functions are covered by the Hermitian quadratic form.
The extension to the retained absolute-current marks uses their symmetric
marked transition matrices; reflection reverses their order.

The calculation reuses the mode-level positivity algebra in
[`SourceLaw.ReflectionPositivity`](../../Lean/SourceLaw/ReflectionPositivity.lean),
particularly `bondGram_nonneg_iff` and its negative-transfer control.
The full Markov conditional-factorization argument above is analytic; it
is not presented as a newly checked Lean theorem or as an application of
the Gaussian-measure theorem to this non-Gaussian process. A two-state
deterministic flip is a counterexample to dropping positivity: it is
stochastic and reversible but gives reflection form `-1` for `(1,-1)`.

For configuration functions, the representation uses
`Omega = (1,...,1)/sqrt(66)` and diagonal multiplication operators `D_f`:

```
E[f(X_0) g(X_n)] = <Omega, D_f K^n D_g Omega>.
K^n = exp(-n H).
```

Complete configurations remain hidden working-state audit observables in
the current primitive interface. The observer test below uses only current
records and does not grant access to those configurations. The constant
ground ket represents the stationary Markov history; it is not a claim
that the native apparatus physically prepares that coherent ket.

## Existing observer current bits

At a retained event the observer records `b=|j|`, zero for a wait and one
for a move. The seam, placement coin and current sign are forgotten.
Count actual native outcomes separately for each bit to obtain `T_0,T_1`.
Both matrices are symmetric and entrywise nonnegative:

```
T_0 = diag(K),   T_1 = K - diag(K),   T_0 + T_1 = K.
```

These are marked transfer insertions, not POVM effects: their sum is `K`,
and entrywise positivity does not make `T_1` a positive operator. For two
retained events separated by `n` unread native attempts, the complete law is

```
p(a,b;n) = pi T_a K^n T_b 1
         = <Omega, T_a exp(-n H) T_b Omega>.
```

All four probabilities are retained and sum to one. For successive events,
the exact law in order `00,01,10,11` is

```
(713/990, 127/990, 127/990, 23/990).
```

Each event moves with probability `5/33`; the covariance of the two move
bits is `1/3630`. This is a prediction of the specified native model.
No laboratory dataset enters it. The covariance is small but strictly
positive, distinguishing the joint law from independent bits with the same
single-event probabilities.

The executable comparison independently constructs the actual native C
Kraus maps for every `(seam,coin,current)`, with amplitudes `1/sqrt(60)`.
The shared CQ runtime groups them by the retained bit and sums all hidden
alternatives as CP branches. Starting from the stationary mixture `I/66`,
it executes two reads with gaps zero, one and four. For every one of the
four records, the exact marked-kernel calculation is compared with the
runtime's full unnormalized 66-dimensional terminal density, including
zero entries. A serialized checkpoint after the first read is independently
replayed and continued through the same second read.

This executes native channel semantics. It does not emit the source pulse
compiler's native words. Its event and record counts are declared logical
resources, and the numerical comparisons are not outward roundoff or
physical service certificates.

## An exact fractional-step obstruction

The spectral interpolation `exp(-s H)=K^s` does not define a Markov kernel
for every nonnegative real `s`. Set `D=I-K`; the exact bound above gives
`0 <= D <= I/3`. The convergent binomial series is

```
sqrt(K) = I - sum_(n>=1) a_n D^n,
a_n = binomial(2n,n) / [4^n (2n-1)],   0 < a_n <= 1.
```

Using the native enumeration's zero-based indices, state 28 occupies ports
`(3,11)` and state 43 occupies ports `(2,4)`. Exact rational multiplication
through degree eight gives the following off-diagonal partial sum:

```
-sum_(n=1..8) a_n (D^n)_(28,43)
    = -809497755979/4777574400000000.
```

The omitted series has operator norm at most
`sum_(n>=9) (1/3)^n = 1/13122`. Each entry's absolute error is bounded by
that norm. Consequently

```
sqrt(K)_(28,43) <= -4008679803811/42998169600000000 < 0.
```

This exact negative entry rules out the logarithm's half-step as a
transition-probability kernel. The integer-attempt reconstruction and its
reflection positivity remain valid.

## Meaning and remaining attachment

The finite positive generator and its ground direction follow from the
actual native configuration law, with no supplied oscillator action.
They describe the stationary history's Euclidean transfer structure.
Writing `exp(-i t H)` by analytic continuation does not establish that an
observer experiences this parameter as physical time or can execute the
corresponding coherent transformations. The committed native update is a
noisy channel, not that unitary.

The C and E instruments have the same classical configuration kernel and
different coherent outputs, as the [action attachment](action.py) checks.
Thus this reconstruction does not select the full quantum instrument.
`H` also need not be local on the one-attempt configuration graph: the
logarithm contains multi-step contributions. A finite gap and a finite
Hamiltonian establish no relativistic quantum field theory, growing
spatial family or empirical agreement.

The next attachment is an observer-access and clock construction that
relates these correlations and their refinement to measured physical
records. A Gaussian fluctuation limit would additionally need a justified
family of independent or suitably mixing sources and a scaling theorem;
it is not assumed in this finite reconstruction.
