# Selecting one source, interface and repair law

The construction target has three primitive selection obligations: the
**carrier architecture**, the **observer interface and its implementation**,
and the **complete repair rule**. Effective fields, transport, clock
relations and interactions must follow from this same process. The existing
scalar and matter Hamiltonians are comparison constructions under declared
inputs until such a derivation attaches them to that process.

This guide organizes the current selection work. It adds no core axiom or
new scientific ledger. The claim registry and the generated
[premise map](PREMISES.md) retain their existing ownership and statuses.

Agreement in complementary bases can force a specified code-transfer channel to be identity; accepting those observations is an interface premise. |

A committed instrument alone does not specify a later use of its uncommitted dilation. |

These are obligations to justify, not three completed selections. Moving an
arbitrary Hamiltonian, coupling, clock rate or target-fitting table into one
of these fields would not derive it. The
[A1 architecture firewall](../docs/AXIOM_REFERENCE.md) requires operational,
quotient-visible, presentation-natural source data without a desired physical
target encoded in them. A2 constrains naturality and projective holonomy;
it does not fix every scalar lift phase. A3 optimizes its declared state
object and admissible domain; it does not select an unrestricted policy or
repair algorithm.

Initial or boundary data must also have an explicit status: selected by the
source, supplied as the instance being studied, or experimentally prepared
through the admitted interface. A family of conditional predictions need
not select one initial state of the Universe. Every claimed prediction must
name which of these quantifiers it uses.

## Selection is relative to accessible observations

For a fixed architecture and interface, two presentations are operationally
equivalent when every admitted intervention history has the same complete
record instrument, including its surviving quantum output and reference
correlations. Presentation changes transport states, controls and readouts
together. They do not supply a free active operation.

Suppose the admitted primitive commits a classical label `r` with Kraus
operator `L_r`. Replacing `L_r` by `exp(i theta_r)L_r` leaves that CP branch
unchanged. It also leaves every finite adaptive history unchanged when later
operations depend only on the committed labels: the branchwise scalar phases
cancel in `M_h rho M_h†`. This freedom is unobservable within that interface
and requires no extra physical parameter selection there.

If the interface instead admits interference between uncommitted record
values, those phases become observable. The complete coherent implementation
then belongs to the repair-rule selection problem. A classical record read
and a complementary coherent read are distinct instruments; their results
cannot be treated as simultaneous readings of one undisturbed record.

The existing [coherent code theorem](../docs/research/COHERENT_SOURCE_CLOCKS.md)
illustrates the positive direction. In its fixed channel domain, one-basis
agreement permits dephasing, while exact agreement in two complementary
bases forces identity transfer, including arbitrary references. The theorem
derives a service from a stronger interface contract. It does not derive
that contract from A1--A3 or select a propagation Hamiltonian.

Likewise the [finite completion theorem](../code/quantum_information/ALGEBRAS_AND_REPAIR.md)
selects an entropy completion after its retained algebra and reference are
specified. On the binary native shell, fixed-seam E is the tracial
conditional expectation onto `M46 direct-sum (I2 tensor M10)`: the 46 states
with equal endpoint loads form the first block, and the remaining twenty
states factor into endpoint orientation and ten spectator locations.
The corresponding full retained-algebra constraint selects that completion.
It does not select the retained algebra, record instrument or physical
interface. Full-carrier E is nonunital, so this binary argument does not
transfer to all 78 inputs.

## The native selection tests

The [coherent continuation](observer/COHERENT_CONTINUATION.md) fixes a
3,960-arc experimental architecture, uniform coherent event embedding `A`,
native reversal `S`, and complete Ramsey interface. Both `S` and
`S(2AA†-I)` have the same first coherent event. Both conserve load, use native
transition support, are real orthogonal, respect proper carrier relabeling,
fix the uniform coherent state and admit the same algebraic time reversal.
Neither has an adjustable continuous parameter. Nevertheless their later
Ramsey probabilities differ. These criteria cannot select between them.

Even the stronger hypothetical requirement of covariance under every
permutation of the sixty event labels leaves two real orthogonal coins
fixing the uniform vector. With `J` the all-ones matrix, such a coin has form `C=aI+bJ`, where
`a+60b=1` and `a²=1`: identity or `2J/60-I`. This stronger permutation
condition is not asserted as an A1--A3 consequence. Both choices preserve
the amplitude disagreement norm `||(I-AA†)v||`; neither is a strict
agreement-descent operation on that workspace.

A separate phase control assigns minus sign to **every moving native arc**
and plus sign to stationary arcs. It preserves the committed C/E CP
branches and proper carrier covariance. For its signed reversal `S_chi`,
the compression is `D=2 diag(K)-K`, with
`Tr(D³)-Tr(K³)=-1/90`. At the same uniform coherent preparation, the
one-step return probability changes from `1` to `529/1089`; the complete
Ramsey plus probability changes from `1` to `28/33`. This signed control
does not fix that uniform coherent ket, and is separate from the two
continuations which do. A tracial stationary density and a stationary pure
coherent state are different constraints.

The [source-executed interface test](observer/source_selection.py) makes the
record-access distinction concrete using the existing C/E dilation and
source controls. A fixed preparation occupies native code addresses one and
two. A two-pulse record phase changes no committed CP branch, including
padding and arbitrary references. A complementary read before commitment
has complete plus probabilities `3/4` and `1/4`, with both fair native coins
retained. Conditional on coin zero, plus probabilities are `1` and `0`;
conditional on coin one, both are `1/2`. Each coin has probability `1/2`.
Committing the record before that read gives `1/2` for both.
The complementary outcome is a new record-basis result, not a native
current label. Its supplied source code services and calibration obligations
are unchanged; these values are model predictions without experimental data.

## What would advance selection

An admissible selection argument must identify which existing source or
observer-agreement constraint excludes an alternative, exhibit the actual
map to that constraint, and retain a counterexample when the constraint is
removed. Covariance alone cannot remove the controls above. A2's projective
chart holonomy is not an established identification of native configuration
loops with identity chart loops; imposing a preferred loop phase would need
that attachment.

The immediate task is to derive which phase-sensitive observations and
agreement constraints the observer interface admits, then apply the existing
completion or channel-fidelity results to those actual objects. Comparisons
with observed propagation may reject complete candidates, but choosing the
reflection because it produces a desired wave is not a source derivation.
Effective physical claims additionally need one compatible extending family,
controlled errors and independent observations, with the time parameter of
each rate stated explicitly.
