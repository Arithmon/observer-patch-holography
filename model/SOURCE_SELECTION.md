# Selecting one source, interface and repair law

The construction target has three primitive selection obligations: the
**carrier architecture**, the **observer interface and its implementation**,
and the **complete repair rule**. Effective fields, transport, clock
relations and interactions must follow from this same process. The existing
scalar and matter Hamiltonians are comparison constructions under declared
inputs until such a derivation attaches them to that process.

This guide organizes the current selection work. It adds no core axiom or
new scientific ledger. The claim registry and the generated
[premise map](PREMISES.md) retain their existing ownership and statuses.

These are obligations to justify, not three completed selections. Moving an
arbitrary Hamiltonian, coupling, clock rate or target-fitting table into one
of these fields would not derive it. The
[A1 architecture firewall](../docs/AXIOM_REFERENCE.md) requires operational,
quotient-visible, presentation-natural source data without a desired physical
target encoded in them. A2 constrains naturality and projective holonomy;
it does not fix every scalar lift phase. A3 optimizes its declared state
object and admissible domain; it does not select an unrestricted policy or
repair algorithm.

Initial or boundary data must also have an explicit status: selected by the
source, supplied as the instance being studied, or experimentally prepared
through the admitted interface. A family of conditional predictions need
not select one initial state of the Universe. Every claimed prediction must
name which of these quantifiers it uses.

For a declared instance, architecture, implemented interface and complete
repair law are legitimate inputs, rather than premises that must be derived
again inside each prediction. The

## Selection is relative to accessible observations

For a fixed architecture and interface, two presentations are operationally
equivalent when every admitted intervention history has the same complete
record instrument, including its surviving quantum output and reference
correlations. Presentation changes transport states, controls and readouts
together. They do not supply a free active operation.

Suppose the admitted primitive commits a classical label `r` with Kraus
operator `L_r`. Replacing `L_r` by `exp(i theta_r)L_r` leaves that CP branch
unchanged. It also leaves every finite adaptive history unchanged when later
operations depend only on the committed labels: the branchwise scalar phases
cancel in `M_h rho M_h†`. This freedom is unobservable within that interface
and requires no extra physical parameter selection there.

If the interface instead admits interference between uncommitted record
values, those phases become observable. The complete coherent implementation
then belongs to the repair-rule selection problem. A classical record read
and a complementary coherent read are distinct instruments; their results
cannot be treated as simultaneous readings of one undisturbed record.

## What would advance selection

An admissible selection argument must identify which existing source or
observer-agreement constraint excludes an alternative, exhibit the actual
map to that constraint, and retain a counterexample when the constraint is
removed. Covariance alone cannot remove the controls above. A2's projective
chart holonomy is not an established identification of native configuration
loops with identity chart loops; imposing a preferred loop phase would need
that attachment.

The immediate task is to derive which phase-sensitive observations and
agreement constraints the observer interface admits, then apply the existing
completion or channel-fidelity results to those actual objects. Comparisons
with observed propagation may reject complete candidates, but choosing the
reflection because it produces a desired wave is not a source derivation.
Effective physical claims additionally need one compatible extending family,
controlled errors and independent observations, with the time parameter of
each rate stated explicitly.
