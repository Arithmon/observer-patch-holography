# A bounded local repair family with a common faithful reference

One small change to the C/E repair law has a positive finite consequence:
an endpoint placement coin biased by two supplied local port weights preserves
a nonuniform faithful reference. Every complete C/E branch is covariant under
that reference's modular action. This constructs a compatible repair/reference
pair. The continuing observer construction below prepares this same quantum
reference, retains a stationary record buffer and executes its dimensionless
modular clock. Port weights, coherent services and physical calibration remain
explicit inputs or obligations.

The [contract](campaign.json) freezes this finite alternative class separately
from the unchanged C/E campaigns. The [implementation](local_bias.py),
[tests](test_local_bias.py) and [exact receipt](results.json) retain the old
fair-coin law as a control. The [observer contract](observer_campaign.json)
separately declares the continuing and coherent service composition.

## Compatibility first, then the update

For the existing twelve-port binary total-two carrier, independently choose
positive integer port weights `theta_i`. The compatibility target is

```text
pi(x) = product_i theta_i^x_i / Z,    sum_i x_i=2, x_i in{0,1}.
```

On a requested seam `(a,b)`, keep the native endpoint floor/ceiling map and
the complete C or E raw-record partition. Replace the fair coin by
`P(coin=1)=theta_a/(theta_a+theta_b)` and
`P(coin=0)=theta_b/(theta_a+theta_b)`. With one endpoint load, these place it
at a or b respectively. Empty and fully occupied binary endpoints stay fixed.
The bias reads no hidden source load or spectator: its two weights and seam
are declared control data.

The classical transition is precisely conditional resampling of pi at fixed
outside configuration and endpoint total. Thus the existing
[`FiniteConditionalRepair`](../../Lean/Thermodynamics/FiniteConditionalRepair.lean)
row-sum, detailed-balance, stationarity and fixed-mixture theorems apply to the
actual endpoint kernel. Exact enumeration checks every premise. Positive
fixed seam weights connect all 66 configurations; self-loops give aperiodicity
and the unique classical stationary law. The quantitative preparation proof
below upgrades this to uniqueness on all quantum source states.

Each quantum record map is `K_b=sqrt(p_coin) P_b`, with P_b the existing native
partial injection. Completeness is checked on both H78 and H66, including
zero raw slots. Pi is faithful only on H66. For decoded current J,

```text
pi(output)/pi(input) = (theta_b/theta_a)^J,
pi^it K_b pi^-it = (theta_b/theta_a)^(it J) K_b.
```

The multiplier is constant within each record block. It cancels in the CP
map, proving modular covariance of the complete instrument with an untouched
reference of any dimension. The sum of its outputs fixes pi. C and E retain
different coherence behavior despite their equal population transition.
This does not assert that the quantum channel is a conditional expectation,
or that passive repair equals modular evolution. The separate modular service
below executes this reference's phases using declared coherent controls.

The existing [regional factorization test](../native_modular_reference/common_caps.py)
applies: all bare two-port number-preserving algebras are invariant under this
product reference's modular action. The additional result here is an actual
changed local repair instrument preserving the same nonuniform state.

## Quantitative preparation and a continuing observer

The [mixing proof](mixing.py) applies to every member of the frozen class,
including arbitrary quantum input entangled with an untouched reference R.
Write Phi for the unread source channel and pi for its product reference.
For every complete native record, the Kraus map is a weighted partial
injection. Distinct input addresses that survive a common record remain
distinct. If r is their maximum one-attempt probability of producing the
same complete record, the off-diagonal source/reference blocks contribute
at most `65 r^n/2` to half trace distance after n attempts. Positivity gives
the dimension-only bound `sum_(i!=j) ||rho_ij||_1 <=65`, independently of R.

For the diagonal part, column minima of the exact rational matrix P^b give
`P^b >= beta nu`, with nu a probability row. Classical contraction and
stationarity then prove the uniform replacement bound

```text
1/2 ||(Phi^n tensor id_R)(rho) - pi tensor rho_R||_1
  <= min(1, 65 r^n/2 + (1-beta)^floor(n/b)).
```

The configuration graph has diameter four. Every admitted moving transition
is at least1/38400; self-loops allow padding to four steps. Thus the whole
class has `beta >=66/38400^4` and `r <=3839/3840`. Both terms tend to zero,
proving that pi is the **unique quantum stationary source state**, rather
than merely a diagonal equilibrium. For the declared25/8 member, exact
integer matrix powers give `beta_20 >33/200`; C has `r=893/990`, E has
`r=7/10`, and any fixed tagged mixture is bounded by C. After1600 attempts,
the common conservative half trace bound is less than10^-6. No floating
eigenvalue or fitted convergence rate is used.

The [continuing instrument](continuing.py) retains the full physical raw
record alphabet, including zero and invalid-address slots. A depth-m FIFO
appends the newest record and exports the oldest. For a word h of m records,
the stationary source/FIFO block is `tau_h=Phi_h(pi)`, not pi times an
independent record distribution. Appending one instrument and tracing the
export preserves this joint state. After n>=m attempts, contractivity gives
the same preparation bound with n replaced by n-m, including any preexisting
untouched R. In particular1601 attempts prepare the depth-one observer to
the stated10^-6 accuracy. This is an unread accessible-state bound: the
complete execution still carries its exported tape and its resource cost.

There is no stationary growing tape and no assertion that the preparation
archive is independent of R or the source. An exact tagged-input control
retains a nonzero correlation in the first exported record for every later
time. Adding that record to the product replacement target would invalidate
the theorem. Record-dependent feedback similarly needs a new joint analysis;
the stationary result uses the fixed positive selector declared in the contract.

For every positive record word, `K_h pi K_h^dagger` is a scalar times pi
restricted to the branch image. Hence the normalized posterior is faithful
on that corner, and its modular action is the restriction of pi's action;
normalization adds only a scalar to its logarithm. This explicitly connects
the actual stationary record blocks to the regional clock. It does not give
physical access to arbitrary support-corner operators.
