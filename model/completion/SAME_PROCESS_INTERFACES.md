# Same-process interface conditions

The finite constructions compose only when their carrier, law, reference,
operations and clock maps agree. The accepted executable contract supplies
those admission conditions; it does not identify a physical particle.

actively reset core. Its universal exact-code optimum has mean excursion

`(25,25,8,...,8)` and has a different stationary core law. Its exact potential

channel identity. A separate clock composes with the logical memory but
does not select a common energy, physical time or moving-particle law.

triplet decoder class. Neither interface identifies a physical family,
