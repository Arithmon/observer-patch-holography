\begin{proposition}[Exact record-assisted restoration]
\label{prop:whitney-charged-record-restoration}
Let each patch hold a pair in \(\mathbb Q^2\). Record its initial pair,
then probe a ring edge by replacing both endpoint pairs \(x,y\) with
\(r=(x+y)/2\). Retain the response \(r\), and restore the endpoints
using the first endpoint's retained baseline \(b\) as
\((b,2r-b)\). Processing the five edges serially restores every patch
exactly. Each patch's pair can be recovered from its predecessor's
response and baseline and agrees with its own retained baseline.
\end{proposition}
\begin{proof}
At the first probe, \(b=x\), hence \(2r-b=y\).
Inductively every probe starts from the original endpoint pairs and
restores them, so the same identity holds on every edge. Each patch has
one predecessor in the ring, which proves the stated decoding rule.
\end{proof}
