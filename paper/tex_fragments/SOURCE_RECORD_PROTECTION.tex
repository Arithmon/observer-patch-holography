\subsection{Protected spatial records and mutable repair states}
\label{sec:source-record-protection}

A population attached to retained records and a population read from live
repair amplitudes obey different evolution laws. The distinction can be
characterized exactly for scalar seam averaging. On a finite port set $I$,
let $T_{uv}$ replace the two endpoint loads by their arithmetic mean and
leave the other loads unchanged. For coefficients $w_i\in\mathbb R$, define
$R_w(N)=\sum_iw_iN_i$.

\begin{proposition}[Linear records preserved by repair]
\label{prop:source-record-protection}
For distinct endpoints $u,v$,
\[
 R_w(T_{uv}N)-R_w(N)
   =\frac{(w_u-w_v)(N_v-N_u)}2.
\]
Thus $R_w$ is invariant under $T_{uv}$ for every input precisely when
$w_u=w_v$. For a specified seam graph, invariance under every allowed
repair is equivalent to constancy of $w$ on each connected component.
On a connected graph every such record has the form
$R_w(N)=w_*\sum_iN_i$.
\end{proposition}
\begin{proof}
Only the endpoint summands change. Substitution gives the displayed defect.
Equality of their coefficients suffices for invariance. Conversely, use the
input with value one at $v$ and zero elsewhere. Along a graph path the
endpoint equalities propagate, proving constancy on components. Grouping
the resulting sum by components gives the claimed factorization.
\end{proof}

The defect, both directions of the invariance criterion, propagation along
arbitrary finite paths, and connected-component factorization are proved in
\path{Lean/Geometry/SourceRecordProtection.lean}. Apply the scalar theorem
coordinatewise to a vector readout. An active seam changes that readout
whenever its two coefficient vectors differ. This describes the specified
linear readout and autonomous pair-mean law. It excludes neither nonlinear
records nor preserved memory, driven evolution, or a different repair law.

For the twelve-port carrier, the live rank-three readback has distinct
coefficient vectors at distinct ports. It therefore changes at every active
seam. This does not change the rank or metric of the response space: those
belong to the repair operator. It changes the point represented by the live
load inside that space. If internal repairs converge to a constant load,
the centered rank-three readback tends to zero.

An exact finite execution distinguishes the two record choices on the
golden population with $q=13$. For each of its $2197$ sites, the initialized
loads use the signed antipodal split of the conservative record. The first
lexicographically ordered unequal intra-carrier seam is averaged once;
the zero record requires no update. All $2196$ active updates preserve total
load and strictly decrease its quadratic potential. Every active carrier's
live spatial address changes, while the $2197$ resulting live addresses
are distinct. For the squared dimensionless read radius $1/13$, the number
of directed metric-neighbour pairs including self-pairs changes from
$294191$ to $32249$; $135123$ unordered adjacency decisions change.
The exact rational event history and independent quadratic-field distance
census are provided in \path{code/source_population/}. This execution uses
intra-carrier repairs only; it is not an implementation of routed
inter-carrier reads.

There is also a simple invariant population extension. Give each carrier
an immutable initialized address register and a mutable port-load register;
let each repair write only the latter. The address population and its
metric-neighbour graph are then unchanged under every repair word, even
though the live amplitudes relax. The same execution retains all $2197$
prepared addresses exactly. The golden population, its initialization and
the protected write footprint are supplied inputs. The causal/count limit
applies to these retained addresses when its read law and measure hypotheses
hold. Availability of a conservative source word alone does not establish
the preparation or preservation of its live readback. A maintained source
population requires a stated protected-record or driven-population law.
