## Verifier scrutiny

The producer and checker use different integer normalization algorithms,
cube-face enumerations, cut-count methods and graph update directions. The
checker replays every reference graph and both initial and intermediate writer
interventions, checks changed values against actual descendants, and compares
full small-box crossing pair enumerations to the analytic finite formulas.
The exact catalog cannot be truncated, duplicated or replaced by empty data.
Strict JSON rejects duplicate keys and nonfinite values; canonical comparison
distinguishes booleans from integers. Acceptance uses explicit exceptions,
not Python assertions. An actual optimized CLI run rejects junk input.

Audit corrections included a route-tube semantic check: an explicit legal
320-step detour passes the endpoint and time bounds but leaves the proved
tube, so even a resealed path digest must fail. Further controls change
intermediate state digests while retaining correct event counts, set action
normalization to zero, fake stability and alter the consumer disposition.
Zero-boundary energy, every cubic monomial and an actual periodic parity
eigenmode have independent algebraic controls.

The receipt pins the scientific source files and the complete original direct
consumer rows. A changed hash is not accepted as proof of scientific agreement:
the verifier recomputes the claimed outputs. Large-n evidence consists of
compact integer cut/moment evaluations, not hidden or claimed full simulations.
