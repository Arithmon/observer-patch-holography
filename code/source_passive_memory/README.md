# Passive memory, reset and ancillary budgets toward M1

This derives three constraints on implementing M1 with the existing scalar
pair-mean operation. It also gives a sharp approximate reset construction.
It does **not** derive the protected export, reset service or readback used
by the current feedback transport. The [contract](CONTRACT.md) fixes this
bounded objective; [AUDIT.md](AUDIT.md) records the review and validation.

The operation is exactly `ScalarSeamRepair.pairAverage`: replace both endpoint
loads by their arithmetic mean, leaving every other coordinate unchanged.
Support, initial preparation and the finite operation word are declared.
No zeroing, copying, inverse repair or hidden observation archive is included
in that word. These are statements about this candidate law, not a selection
of it from OPH's primitive ontology.

## 1. Nonlinear readouts cannot evade the global record classification

Let a finite support be connected and let `F` be any state-only readout with
arbitrary codomain. Suppose, for **every nonnegative state** and every allowed
edge, `F(P_uv x) = F(x)`. Then, for any chosen root,

```
F(x) = F((sum_i x_i) * e_root).
```

Conversely every function of total load satisfies that invariance. This
extends `SourceRecordProtection` beyond linear readouts: continuity,
measurability and a finite output alphabet are unnecessary. In particular,
two nonnegative states with the same total cannot be distinguished by such
a protected record. This leaves arbitrary information encoded in the total
itself; it does not impose a finite information capacity on an ideal real.

The proof uses a finite equality chain. For nonnegative background `z` and
addend `a`, the states `z+a*e_u` and `z+a*e_v` have the same image under their
edge mean. Invariance identifies their readouts. Following connected paths
and adding the coordinates concentrates the argument at the root. **The
concentrated state is not claimed to be physically reachable by averaging.**

`SourceNonlinearRecord.lean` proves this on the nonnegative cone. The retained
four-port control records six pairs of equal-image witnesses, with all 12
separately prepared inputs explicit. They are not a six-step transport tape.
Independent breadth-first search of the pinned level-3 W12 capture finds
15,360 scalar ports, 46,050 undirected edges and one connected component;
the builder checks the same census by union-find. This is a finite check of
the declared captured support, not a kernel certificate of its connectivity
or evidence that all its means are physically selected.

The universal input quantifier is essential. The theorem does not exclude
restricted admissible code spaces, state-dependent menus, protected separate
components, or stored observation histories. It therefore does not invalidate
the history-dependent protocol in `SourceSeamPathTomography`.

## 2. Exact native-zero reset fails; approximate reset has an explicit cost

If every initial raw load is nonnegative, a register initially containing
`a > 0` satisfies, after any finite word with `m` incident means,

```
final_load >= a / 2^m > 0.
final_load <= epsilon  implies  a <= 2^m * epsilon.
```

Ancillary registers may change arbitrarily under that word; none must return
to its initial state. The result applies to each realized word of an adaptive
protocol as well. An exact reset to raw scalar zero is thus not generated by
finite nonnegative pair means, even when an ancillary reservoir is consumed.

The lower bound is sharp over supports providing `m` fresh zero neighbours.
Initialize registers `0,...,m` to `[a,0,...,0]` and average `(0,1)`, then `(0,2)`,
through `(0,m)`. The final source is `a/2^m`; used neighbour `j` retains `a/2^j`.
This costs `m` means, `m` prepared zeros, `m+1` allocated scalar registers,
`2m` reads and `3m+1` writes including initialization. Preparation is a supplied
initial condition, counted as assignments, not a derived physical process.
`SourcePassiveReset.lean` proves the full state, length and finite support of
this construction; its natural-number indexing never touches beyond `m`.

For a desired positive tolerance, the necessary incident count is the smallest
nonnegative integer `m` with `2^m * epsilon >= a`. Fresh zero neighbours suffice
at that count. This is not an optimal space bound among all reset schemes.
The growing-star construction is not an arbitrary-depth construction on a
fixed-degree W12 port. The captured control uses just five actual intra-carrier
neighbours, with the six port identities explicitly mapped. Other captured
ports are outside this six-register subprogram; it is not a full-population
execution. The complete support census and this small execution are separate.

The retained cold-star family uses `a=3/2` and `m=0,1,4,12,32`. Reusing one
initially zero neighbour eight times instead leaves both loads at `3/4` after
the first mean. A positive used neighbour cannot become an exact fresh zero
through further finite nonnegative means. No refreshing service is assumed.

This gives a concrete contribution to the existing feedback error ledger:
with otherwise exact `SourceFeedbackTransport.receive`, receiver residual
`r` yields output `payload+r`. A cold reset supplies `r=a/2^m` for the stated
initial receiver load and fresh-zero menu. Export, protected readout, factor-two
decoding, cleanup and any route-wide resource supply still require their own
implementation. This does not replace the six-event feedback hop with a
native pair-mean hop.

PR #913's reusable storage bound is conditional on its feedback primitives.
The consumed zeros here do not establish a native implementation within that
same reusable register bound.

## 3. Closed reuse and balanced copy consume quadratic resources

For any finite real-valued register set, including **all** ancillas, define
`Q(x)=sum_i x_i^2`. One operation satisfies

```
Q(P_uv x) + (x_u-x_v)^2/2 = Q(x).
```

`SourcePassiveMemoryBudget.lean` sums these exact losses over an arbitrary
finite word. Equality of initial and final Q holds exactly when every
scheduled seam already agrees and every mean is trivial. Consequently an
exact cycle restoring the whole finite state cannot contain an active mean.
This says nothing about a driven open cycle whose environment changes.
Q is a scalar convexity functional; no physical energy, entropy, work, volume
or clock is identified with it.

Total-load conservation alone misses balanced copying. In deviations about
a common baseline, consider

```
[a,-a,0,0 ; r]  ->  [a,-a,a,-a ; s].
```

The first two rails hold the record, the next two are initially blank, and
`r,s` are the complete ancillary states. The derived budget is

```
Q(s) + 2*a^2 + loss(word) = Q(r).
```

For `a != 0`, exact copying with `s=r` is impossible even though it would
preserve total load. Shifting every register by a common baseline commutes
with every mean; the argument is not an artifact of using negative raw loads.

The exact nonnegative control uses baseline 4 and `a=1`:

| Stage | Complete raw state | Q about baseline 4 | Accumulated loss |
| --- | --- | ---: | ---: |
| Prepared | `[5,3,4,4,6,2]` | 10 | 0 |
| Mean `(2,4)`, then `(3,5)` | `[5,3,5,3,5,3]` | 6 | 4 |
| Output cleanup `(2,3)` | `[5,3,4,4,5,3]` | 4 | 6 |

The ancillary Q falls from 8 to 2; its cost 6 is output Q 2 plus copy loss 4.
The hypothetical catalytic target `[5,3,5,3,6,2]` has the same total load 24
but Q 12, exceeding the prepared Q 10. It is an obstruction control, not an
executed trace. The preparation `[6,2]` already encodes the payload: this is
**not a copier for an unknown input**. Cleanup resets the *encoded* output
to `[4,4]`, which illustrates why the native-zero theorem must not be extended
to all logical reset encodings.

## Evidence and reproduction

The 40 Lean theorems are transitively checked against the standard axiom
allowlist `propext`, `Classical.choice`, `Quot.sound`. The audit rejects
`sorryAx` and compiler-trusted Boolean reduction as negative controls.
`Geometry.lean` imports it; Python checks coverage of every new theorem.

`controls.json` retains all eight executions (65 means), all final ancillas,
consumed writer identities, rational values, resource counts and six fibre
witnesses. `verify.py` decodes that file and independently reconstructs each
specified experiment, without importing its builder. Source/proof/toolchain
and captured-support hashes bind both retained artifacts to their inputs.
Exact fractions are canonical strings, not floats. The 121 additional small
words of length at most four exercise prefix conservation and positivity;
they are regression controls, not the proof of the universal claims.

From the repository root:

```sh
python code/source_passive_memory/verify.py
python -m pytest -q code/source_passive_memory
cd Lean
lake build Geometry.SourcePassiveMemoryAxiomAudit
```

To regenerate intentionally after reviewing an input change:

```sh
python code/source_passive_memory/build.py
python code/source_passive_memory/verify.py --write-receipt
python -m pytest -q code/source_passive_memory
```

The verification command checks the existing receipt by default. The dedicated
Windows/Linux workflow runs the controls; Lean CI builds the changed modules.
The frozen mandatory runner and its source-projection hashes are preserved.

## What M1 still needs

This work removes the assumption that nonlinear decoding or changing finite
ancillas alone can turn unrestricted passive pair means into exact reusable
feedback. It also derives a finite-error reset implementation and its explicit
prepared-zero cost. It does not select a source population, memory sector,
schedule, read law, finite precision or physical clock.

A next constructive step must specify an admissible memory encoding or a
supplied reservoir/driving law, derive its protected read/write behaviour,
and charge preparation, refresh, error and locality across repeated hops.
Restricting the repair menu may preserve separate component totals, but that
restriction and the ability to read and rewrite those totals would themselves
need justification. The existing supplied feedback and quantum heat-bath
models cannot be relabelled as consequences of the scalar mean law.

Related: the bounded linear obstruction in issue #778, feedback transport on
main, routing refinements in PR #913, and the remaining source-selection and
common-world obligations in #779/#740. This research branch starts directly
from main and closes none of those broader obligations.
