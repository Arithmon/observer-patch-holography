# Passive-memory requirements for M1

## Objective

Determine what exact protected records and reusable feedback can follow from
the finite scalar pair-mean law already used by the source model. Discharge
specific implementation premises where possible and identify precise
obstructions otherwise. Do not select a new physical law by declaration.

## Deliverables

1. A characterization of arbitrary, including nonlinear, state-only records
   invariant under every allowed pair mean on all nonnegative input states.
2. A finite-word reset bound that retains changing ancillary registers, plus
   a matching approximate construction with its prepared-zero cost explicit.
3. An exact quadratic-loss ledger and the resulting boundary on closed
   reusable memory cycles and balanced copy operations.
4. Standard-axiom kernel audits, independently replayed rational controls,
   adversarial tests, and a self-audit stating all remaining M1 assumptions.

## Exit

Theorems and exact finite controls for this specified operation class, with
every preparation, changed ancillary state, operation and decoder premise
visible. No universal impossibility for other laws, encoded logical resets,
restricted admissible code spaces, history-dependent records, open driven
systems or quantum operations follows. No physical energy, clock or volume
interpretation is assigned to the quadratic scalar functional.

The frozen mandatory runner and existing scientific receipts remain intact.
