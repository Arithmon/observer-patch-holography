64-site golden scalar action. It accepts no experimental outcomes. Its
Weyl-algebra interpretation requires access to all real Weyl parameters;
the recorded classical field values do not establish that access.

Reproduce from the RER root:

```sh
python3 code/source_scalar_regional/regional_time_slice.py --write
python3 code/source_scalar_regional/verify_regional_time_slice.py
python3 -m pytest -q code/source_scalar_regional/test_regional_time_slice.py
```

coordinate access costs, cross-time canonical brackets, and every missing
collar-row counterexample. The independent verifier uses the existing
edge-energy assembly in `Q(sqrt(5))`; it neither imports the producer nor
repeats its elimination algorithm. The `parent_sha256` map identifies the
consumed source definitions. It does not assert replay of historical field
traces or quantum outcomes.

field state, boundaries, versioned readback, records and feedback. The
present certificate states which additional field-observable access is
needed for a regional canonical algebra. Native availability of these
operations, physical regions and clock calibration remain separate inputs.
