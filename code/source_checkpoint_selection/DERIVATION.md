# Native checkpoint selection and the shortest two-record pipeline

The temporal-recovery work proved how to recognize readable records and
how to preserve their future recoverability. Its probabilistic progress
result still took a full IID proposal law as a premise. This work derives
an actual finite schedule distribution from an explicit checkpoint problem
and then classifies its shortest histories on a whole path family.

The result is a mathematical selection theorem for the declared scalar
interface. It does not prove that canonical A1 supplies this public record
map, deadline, complete move grammar, reference or entropy cover. In
particular, imposing successful publication changes the feasible set used
by the previous unrestricted-proposal experiment.

## Record grammar and continuation

Let X be the admissible preparations, r:X->R the public record map, o:X->O
the retained observation and s:X->S the current scalar state. Say o
determines r if equal observations imply equal records for every pair in X.
This is equivalent to agreement of every test g(r), including nonlinear
tests. Boolean predicates alone suffice: test equality to r(x). For a
record tuple it is equivalent to agreement of every primitive coordinate.
Thus the coordinate grammar is complete for the algebra generated by r;
it does not secretly assume the full A1 operational algebra is generated
by those coordinates. A different injective encoding of r changes nothing.

The exact continuation condition is

    o(x)=o(y) and s(x)=s(y)  =>  r(x)=r(y).

Necessity follows because a common native continuation cannot distinguish
equal current states with equal past records. Sufficiency follows from the
connected-support calibration theorem: sample the current receiver, then
use its topology-derived native plan to recover the entire current state.
The old record together with that state determines r. This works even if
irrelevant distinctions in X have already been lost. There is a completing
word with 2B+N<=N^2. `HasRoot` is essential and retained explicitly.

These results, including the finite connected composition, are kernel
checked in SourceCheckpointMeaning and SourceCheckpointNative. For the
linear source controls, the complete agreement grammar is precisely the
requirement that every primitive record row lie in the native observation
span. The decoder or dual null certificate proves each alternative for all
real preparations, rather than only for the nine signed test payloads.

## Exact finite information projection

Fix a horizon T and a complete finite alphabet A of native moves in the
chosen interface. A history w is good exactly when its retained native
observations determine r. The feasible family is the full simplex supported
on those good histories. It is nonempty once a bounded completing word is
available; extra allowed means preserve already retained observations.

Let R(w)>0 be the inherited full-history reference, normalized on all
histories, and Z=sum_good R(w). The unique KL minimizer is

    Q(w) = R(w)/Z for good w, and 0 otherwise.

For any feasible p,

    D(p || R) = -log Z + sum_good Q(w) klFun(p(w)/Q(w)),
    klFun(t) = t log(t) + 1 - t.

Each summand is nonnegative, with equality only when p(w)=Q(w). Zeros in p
are allowed and contribute klFun(0)=1. This proves existence, uniqueness
and the information cost -log Z; it does not presume an optimizer.
SourceCheckpointEntropy checks this argument in Lean. On the accepted
subtype it works for arbitrary faithful inherited reference weights.

For a factorized reference with positive move weights a(c,e), define

    H_0(c) = 1 if c publishes r, otherwise 0;
    H_(t+1)(c) = sum_e a(c,e) H_t(advance(c,e));
    K_t(c,e) = a(c,e) H_(t-1)(advance(c,e)) / H_t(c).

Here c is a response checkpoint over all source preparations, not the
realized payload. The controller therefore sees no unknown input or future
sample. H is computed by enumerating native transitions and checking
observation kernels. An exact sum theorem identifies H with all native
continuation words, without omission or duplication. H>0 iff some word
publishes. The kernel is normalized at every reachable node and its product
telescopes to Q. Its positive paths are exactly the good histories. This
constructs a causal implementation; no failed physical run is executed and
then dropped. For a general history-dependent reference the same recursion
uses the entire prefix as its state. Unnormalized edge weights may be used
only with the resulting product reference explicitly declared; the controls
use constant edge weights so the all-word normalizer is (sum a)^T.

The Lean policy module proves the exhaustive mass identity, feasibility,
normalization, telescoping and support. The native composition proves that
positive continuation mass retains the public meaning and every positive
selected word publishes it for all admissible interventions. No IID law or
fairness assumption about the selected process is needed.

## Sharp two-record path theorem (analytic)

Take the path 0--1--...--d, d>=1. Initially the only unknown deviations from
a known common baseline are x at port 0 and y at port 1. Every other
deviation is zero. The receiver is d; retain its initial sample and every
sample after a mean. Edge i averages ports i and i+1. Require both x and y,
not just their sum. Only path edges are allowed in this isolated grammar.

**Theorem.** The smallest successful word length is 2d-1. At that length
the successful histories are exactly the linear extensions of two waves:

    F_1 < F_2 < ... < F_(d-1),
    S_0 < S_1 < ... < S_(d-1),
    F_(j+1) < S_j for 0<=j<=d-2.

F_i and S_i both denote edge i; S_0 is its only edge-0 event. For d=1 the
first wave is empty and the receiver's initial sample already gives y.
There are Catalan(d-1)=binomial(2d-2,d-1)/d successful histories. Every one
has the same two informative receiver responses

    u = y / 2^(d-1),
    v = x / 2^d + (d+1)y / 2^(d+1).

**Cut lower bound.** Edge 0 must occur to transmit x. Each cut edge i>=1
separates both independent unknowns from the receiver. If it occurs at most
once, every downstream scalar and receiver sample depends on the unknowns
through the one scalar transmitted by that crossing. The downstream state
starts at zero deviation; native means cannot create a second independent
source direction without another crossing. Rank two is impossible. Hence
edge 0 occurs at least once and every other edge at least twice, requiring
at least 1+2(d-1) means. This is a rank argument over all real inputs, not
an argument from one favorable payload. Extra edges, relay preparations or
side channels change the interface and do not inherit this bound.

**Necessity of the precedence constraints at equality.** Every crossing
budget is now saturated. The first crossings F_i must move outward in
order: if F_i preceded F_(i-1), it would average two zero deviations and
leave only one effective crossing of that cut. S_0 must follow F_1 when
d>1; otherwise averaging ports 0 and 1 erases their independent difference
before any remote sample. For each i>=1, F_(i+1) must precede S_i. Otherwise
both crossings of edge i finish before any crossing of i+1. At that time
the entire downstream region contains only the single scalar held at i+1;
edge i is exhausted, so a second source direction can never enter. These
are exactly F_(j+1)<S_j, including the initial erasure case j=0. Finally
the second crossings S_i must move outward in order. Inductively x cannot
cross cut i-1 until S_(i-1), since its first crossing precedes arrival of x.
If S_i came earlier, cut i would be exhausted before x arrived.

**Sufficiency and responses.** Incomparable events in this poset can only
be F_i and S_j with i>=j+2. Their edges are disjoint, so their native means
commute. Any two linear extensions are connected by swapping adjacent
incomparable events: move a first minimal event left, then induct on the
remaining events. Thus the final state equals that of the serial first
wave followed by the serial second wave. Before F_(d-1), the precedence
constraints keep the second wave from overtaking the first, so its receiver
sample is y/2^(d-1). In the serial word, after the first wave the relay at
j, 1<=j<d, holds y/2^j; the receiver holds y/2^(d-1). After S_j for j<d-1,
the outward value is x/2^(j+1)+(j+1)y/2^(j+2), by direct induction on the
pair mean. The final average gives v above. Its x coefficient is nonzero,
so the two rows are independent. The d=1 formula is the single mean.

**Counting.** Remove the final S_(d-1). The remaining two ordered waves
have d-1 events each, and every prefix has at least as many F events as S
events. These are precisely Dyck words. Reflecting a first prefix that
violates this inequality gives binomial(2d-2,d) bad balanced words. The
difference from binomial(2d-2,d-1) is the stated Catalan count. No other
minimal native histories satisfy the cut constraints.

**Reference independence at the minimal horizon.** For any positive
time-homogeneous edge weights a_i, every shortest successful word has the
same reference numerator a_0 product_(i=1..d-1) a_i^2. Consequently the
unique selected law is uniform over these Catalan histories for *every*
reference in that class. The grammar and deadline are still supplied; no
invariance argument is used to choose an arbitrary full A3 reference.
At a longer deadline the multiplicities vary and this cancellation need
not hold. The tilted-reference controls demonstrate that boundary.

The classification and Catalan necessity proof are analytic, not Lean
formalized. SourceCheckpointPipeline kernel-checks actual native disjoint
commutation and the reconstruction/error algebra. The independent verifier
enumerates every shortest-horizon word through d=5 (1,969,761 words total),
and every positive poset history through d=10 (6,918 histories total). The
producer generates Dyck words, while the verifier generates linear
extensions from prerequisite sets and replays independent scalar bases.
Every response and word is committed by a reproducible digest.

## Precision and work

Decoding is explicit:

    y = 2^(d-1) u,
    x = 2^d v - (d+1) 2^(d-2) u.

With independent deterministic sample errors bounded by epsilon, the
two-sample decoder's sharp error coefficients are 2^(d-1) for y and
(d+5)2^(d-2) for x. Opposite error signs attain the latter. These identities
are kernel checked; they do not bound accumulated mean-rounding errors or
establish available physical precision. The native work is 2d-1 means,
4d-2 scalar mean reads and writes each, and 2d retained samples under the
declared sampling convention. Preparation and controller work are separate.

The controls execute their entire horizon, even when publication becomes
possible earlier. Every captured-path preparation charges all 15,360
support writes, although only five ports subsequently participate. Planning,
exact arithmetic, retained sample memory, decoding and random-number
generation are host interfaces whose physical implementation is unsupplied.

## Finite results and deadline compatibility

For the captured path 0,1,14,23,45, individual records cannot be published
within six means. At seven means exactly five of 16,384 full reference
words succeed. The derived controller selects them with probability 1/5,
and every selected trajectory executes seven means and retains eight
samples. The aggregate x+y needs only four means and does not determine
either individual record. This is an explicit operational distinction
between two meanings on the same source, not full-axiom independence.

At eight means, 104 of 65,536 captured words publish both records. The first
edge probabilities are (0,94,5,5)/104. The seven-mean law starts on edge 1
with certainty. Thus independently optimizing different deadlines is not
projectively consistent, already at the first move. A compatible temporal
tower requires an additional compatibility theorem for the *actual*
checkpoint/reference family; simply invoking A3 again at each horizon is
invalid. The same issue is visible on the smaller chain: its five-mean law
starts on edge 1, while the six-mean law starts on edges 1 and 2 with
probabilities 19/21 and 2/21. Choosing locally uniformly among still-feasible
moves therefore fails to implement the global optimizer.

## What this closes, and what still selects M1

Within the specified scalar record interface, successful native scheduling
is no longer a supplied word or an IID occurrence assumption. Its complete
finite grammar, nonempty feasible domain, unique optimizer, causal policy,
sharp shortest two-record order and exact costs have explicit derivations.
The path result covers every length and every positive stationary
edge-product reference at the minimal deadline, beyond a small simulation.

It does not select which operational records must be public. A1's
availability of checkpoint interfaces does not entail mandatory publication
of these two records by this deadline. A2 tests naturality on an already
typed accepted domain; it does not choose that domain. Canonical A3 fixes a
state in its actual supplied feasible space and does not authorize adding
this terminal constraint. Nor does the isolated path grammar instantiate
the faithful complete port-response map D, endogenous A2 transports, the
full constraint grammar, or an actual source-selected entropy cover.

M1 still needs source selection of the public record population and metric
menu (including L/sqrt(q)), compatible geometric/refinement identification,
and the link between native computation and the required immutable-version
semantic order. Physical controller, precision, storage and length
identification remain unsupplied; a laboratory clock is a separate M2
attachment. The full-component recovery theorem supplies no particular
proper metric ball. A cost-balancing radius or a minimum-deadline preference
would be an added objective, not a derivation from canonical A1--A3. No full
A1--A3 countermodel or completed M1 derivation is claimed.
