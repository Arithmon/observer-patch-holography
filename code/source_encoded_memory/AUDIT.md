## Mathematical and interface review

1. **No hidden payload-dependent ancilla.** Only the original two rails depend
   on the unknown `a`; every destination starts at `[b,b]`. `copy_native` is
   universal over the entire amplitude function. Both source and destination
   change to amplitude `a/2`, unlike a same-amplitude catalytic copier.
2. **No contradiction with passive-memory obstructions.** Logical clearing
   restores `[b,b]`, not raw zero. The complete analog state loses Q on every
   active copy; it is not a closed cycle. Source sign survives the specified
   read word, not arbitrary means on all nonnegative states.
3. **No free observation archive.** Checkpoints verify actual output states
   after two native means. Their JSON storage is an external audit artifact,
   not a memory service generated by the law. Comparison, headers, versions,
   controller and scheduling remain supplied.
4. **No hidden intermediate state.** Each mean retains both read values and
   consumed writers. During a partially completed copy the individual cells
   need not be balanced. Cleanup is scheduled only after both means. Native
   reset reads the old payload-bearing rails; its ancestry is not deleted.
5. **No noise reset.** The maximum-coordinate error estimate includes signed
   disturbance of idle registers. Common-mode error survives encoded reset.
   The all-state bound does not require noise to keep raw loads nonnegative;
   exact tapes do, and their every prefix is checked. A physical noisy
   nonnegative implementation would additionally owe that admissibility.
6. **No false ambiguity inference.** Failure of the conservative accumulated
   bound is labelled uncertified. The separate terminal ambiguity control
   explicitly supplies the same observation for two opposite preparations.
   The exact inverse gain is an analysis operation, not a native amplifier.
7. **No unsupported locality claim.** The captured control uses ports
   `[0,1,5,9]` of one carrier. The capture contains no direct two-cell square
   spanning two carriers; its finder has a synthetic positive control.
   Longer routed gadgets are not excluded. The 25-cell ladder is separately
   declared, and the 64 repeated local hops are not a spatial distance.
8. **No hidden machine-capacity claim.** Four rails suffice for the repeated
   control, but the exact rational value tally grows to 530 bits at a copied
   state. Program, identifiers, arithmetic workspace, physical comparator and
   the retained audit tape are excluded from that explicitly limited tally.

## Adversarial checks and corrections

The verifier shares only serialization with the producer. It composes a full
rational averaging matrix rather than updating a generated tape's values.
It checks the experiment against its own fixed specification; a coherently
valid trace for the wrong signed input is rejected. Mutation tests reject
invented reset/copy operations, stale writers, omitted cleanup, false
preparation, occupied blanks, hidden source attenuation, false checkpoints,
changed embeddings, resource undercounts, false noise verdicts and source-pin
changes. Duplicate JSON keys, floats, Boolean number aliases and noncanonical
fractions fail. Poisoning every producer entry point does not affect replay.

Independent arithmetic controls vary the unknown amplitude, destroy the
protocol by removing its blank-target or scheduling precondition, retain
common-mode reset error, exercise disturbed reuse for both signs, and check
terminal ambiguity and analog gain. These tests do not replace the universal
Lean proofs or claim measured hardware errors.

The initial static proof scan incorrectly matched the ordinary word "admit"
in a comment; it now excludes comments and retains the actual transitive
kernel audit. Explicit UTF-8 reads fixed a Windows-only test decoding error.
A Windows shell encoding conversion also corrupted two Lean command arrows;
the kernel rejected the audit file. The arrows were corrected, its input pin
was regenerated, and the complete build and real audit passed. None of these
repairs changed the mathematical protocol or relaxed the axiom allowlist.

An isolated probe declared an extra axiom and a theorem that used it. Ordinary
Lean compilation accepted it; the actual new audit rejected its transitive
axiom. The in-module negative controls also reject `sorryAx` and
compiler-trusted Boolean reduction. CI explicitly includes this audit in its
default target list, so dependency-only changes cannot bypass it.
