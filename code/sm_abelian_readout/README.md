# Continuous charged readout bounds

This consumer bounds the nonlinear classical Cartan-scalar current and a
spatially distinct scalar-intensity detector on the same prepared golden
family and action as `../sm_abelian_reduction/`. The observer-like sites
hold local scalar/connection state, read incident ports, retain versioned
records and apply electric feedback. Their action and addresses are supplied.

From the repository root:

```sh
python3 code/sm_abelian_readout/readout.py
python3 code/sm_abelian_readout/verify_readout.py
python3 -m pytest -q code/sm_abelian_readout/test_readout.py
```

`readout.py --write` builds the certificate. The independent verifier imports
no producer, recomputes force bounds through normalized one-dimensional
tensor rows, and freshly reruns the immutable parent's independent verifier.
All bounds use exact rational arithmetic with a proved golden-root bracket.
The analytic first-exit and Taylor proof is in the owning paper fragment
`paper/tex_fragments/CARTAN_SCALAR_READOUT.tex`.

The exact initial conditions define the continuous IVP. Stored binary64
records are exact dyadic data for the separate checkpoint comparison;
they are not silently substituted as that IVP's initial condition.
Actual readout events, latest writers and values determine the nine
completed checkpoints. The intermediate first kick has no assigned exact
IVP time. The ideal gauge-copy reference is gauge equivalent to the baseline;
its rounded stored fields are compared to that reference by the same bound.

This is a classical fixed-family nonlinear readout enclosure. It neither
encloses every numerical state coordinate nor transports the separate free
q233 quantum detector estimate. Native action/population selection,
physical time, full fermion dynamics and observed Born outcomes remain open.
Historical parent receipt bytes and their narrower scope are unchanged.
