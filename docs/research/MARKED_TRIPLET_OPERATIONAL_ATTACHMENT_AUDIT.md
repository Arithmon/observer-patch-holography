## Decision and claim classes

**PHASE_0_STOP**:
`NO_SOURCE_BOUND_OPERATIONAL_ATTACHMENT_IN_AUDITED_SOURCES`.

The audited native observers provide complete instruments and continuing
histories on their specified carriers. They do not provide the particular
common-object interface needed to compare the spatial slow triplet with the
two internal response triplets as alternative operational realizations.
Consequently no finite triplet-discrimination history or probability
difference is defined here. This conclusion quantifies over the interfaces
actually specified in the audited paths; it is not a universal impossibility
theorem for OPH observers, source completions or representations.

| Claim class | Adjudication | Evidence and boundary |
| --- | --- | --- |
| Source-derived finite representation facts | GO, within the fixed marked action | Existing exact marked-triplet producer and independent verifier; no change to their verdict. |
| Declared architecture inputs | Retained as inputs | C/E candidate, protected caps, controller and schedule, coherent proper-code load/export and routing, service accuracy. Compilation is conditional on these services. |
| Derived mathematical consequences | GO, within those inputs | Native preparations, reference-safe instruments, finite clocks and complete tomography have their existing source contracts. An equivariant vector-space map is not by itself a preparation or channel. |
| Operational triplet comparison | NOT_DERIVED in audited scope | Missing common state/observable interface and transport of preparations and complete instruments. Neither equality nor a nonzero discrimination probability follows. |
| Physical interpretation | NOT_DERIVED | No physical golden embedding, laboratory clock, empirical identification or selection of an internal block is inferred. |

The load-bearing missing premise is a **source-derived operational attachment**,
with state, observable, intervention, record and reference semantics. Adding
an arbitrary basis embedding would supply that premise rather than derive it.

## The compiler connection and the missing signature

The compiler is a substantive source connection, not merely a hash dependency.
`model/observer/source_scalar/compiler.py:_source` reads all twelve `D_p`
from the response tape and checks ten exact control rows from
`code/m1_source_realization/receipt.json`. It realizes logical `X,Y,Z,I,J`
using those six-level controls; `J` uses the relative-block phase.
`transfer_kraus(d)` specifies full export to a code plus failure, for declared
proper codes `d=2,4`. `source_discrimination/circuit.py:encode` then labels
native configurations in a nine-qubit, 512-address register. This connection
must not be described as absence of source-compiled native operations.

Its logical codes and their coherent service are declared. The compiler does
not assert that its code service intertwines the fixed 12-port action with
the spatial slow band or supplies an operational Galois conjugation. Selecting
upper-block matrix coordinates for gate synthesis is not a derivation of
which spatial/internal realization a physical observer occupies.

For the proposed comparison, the absent signature is a source specification
of the admitted state spaces and observable dictionaries for `V_slow` and
the internal alternatives `W_upper,W_lower`, together with operational
encodings into a common native carrier and transported complete branch maps.
An attachment would need to state, for every admitted input and untouched
reference, how preparation, each intervention, every record/failure output
and surviving state correspond. Its action condition must be

```text
T rho_spatial(g) = rho_internal(g) T
```

or the corresponding condition with a source-derived `theta(g)`. The latter
cannot be chosen after observing a character sign. A real response vector
is not silently treated as a quantum density, and no isometry, CP channel or
ancillary triplet register is supplied by this audit. Equality of selected
scalar probabilities would not establish equality of complete instruments.

The source search followed the named modules' actual imports through the
native Kraus, six-level compiler and code-embedding paths. It also inspected
the existing `common_source/slow_geometry.py` current attachment,
`identifiability_checks/rule_observability.py` interface restriction,
`programme_obstruction_audit` carrier/triplet controls, and the Stage-2
source-current inventory. References to `response.json` in other model
packets were checked as potential joins; their presence alone supplies no
covariant triplet transport. This is a source review, not a machine proof
that every possible map is absent.
